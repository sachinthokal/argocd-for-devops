Volume

A Volume defines how and where storage is provisioned. It can be backed by ephemeral storage, host paths, secrets, configmaps, NFS, cloud volumes, or persistent storage solutions.

VolumeMount

A VolumeMount attaches the Volume into a container filesystem. It selects a path and controls whether the mount is read-only or writable, making data available to the running application.
